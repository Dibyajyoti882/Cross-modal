# CrossEcho: Cross-Modal Image-to-Audio Synthesis for Visually Impaired Navigation

## Final-Year B.Tech Computer Science & Engineering Capstone Project
### Full Stack AI Web Application & Data Collection System

---

## 1. Project Overview & Abstract
**CrossEcho** is an assistive technology system designed to aid visually impaired individuals in spatial navigation. By capturing real-time environmental imagery using wearable or handheld cameras, the system uses deep learning to locate physical items in the surroundings, estimate their distance and position, and provide auditory feedback.

The project currently features two main components:
1.  **The Web Application Prototype**: A secure, premium web dashboard providing a Live Navigation HUD that executes YOLOv8 object detection, MiDaS depth estimation, and prioritized TTS (Text-to-Speech) feedback.
2.  **The Data Collection Module**: A standalone automated data collection script (`collect_data.py`) used by researchers to capture real-world navigational data (images, object distances, angles, positions) using a standard webcam.

## 3. Database Schema

### Users Table (`users`)
Stores registration records and login credentials (passwords hashed via Werkzeug).
*   `id`: Integer (Primary Key, Autoincrement)
*   `username`: Text (Unique, Not Null)
*   `email`: Text (Unique, Not Null)
*   `password_hash`: Text (Not Null)

### Navigation History Table (`navigation_history` / `detections`)
Logs successful object detections linked to the active operator session.
*   `id`: Integer (Primary Key, Autoincrement)
*   `user_id`: Integer (Foreign Key referencing `users(id)`)
*   `object_name`: Text (Not Null)
*   `confidence`: Real (Not Null)
*   `distance`: Real (Estimated depth in meters)
*   `direction`: Text (Left/Center/Right)
*   `timestamp`: Datetime (Defaults to current timestamp)

## 5. Running the Data Collection Module (For Researchers)
If you need to collect real-world data to build a custom dataset for model training or research analysis, use the automated collection module.

1. Run the data collector script:
   ```bash
   python collect_data.py
   ```
2. The webcam will activate and start logging data.
3. Move objects around or move the camera to collect diverse scenarios.
4. The script continuously captures images to `dataset/images/` and appends detailed records (Distance, Angle, Depth Category) to `dataset/records.csv`.
5. Press the `q` key on the video window to stop collection safely.

---

## 6. Running the Web Application (For End-Users/Operators)
Start the Flask development server:
```bash
python app.py
```

Upon launching, the system will:
1. Initialize the SQLite database `crossecho.db`.
2. Load the heavy AI models (YOLOv8 and MiDaS) in a background thread to prevent blocking.
3. Bind the server to `http://127.0.0.1:5000`.

**Web UI Walkthrough:**
1.  **Landing Page**: Open your browser to `http://127.0.0.1:5000`.
2.  **Authentication**: Register a new user and log in to access the secure dashboard.
3.  **Dashboard**: Review the statistics panel for your total navigation logs.
4.  **Live Detection HUD**:
    *   Click **Start Navigation** to start the Live HUD.
    *   The browser will request webcam access. Once granted, the client will capture frames and send them to the backend API.
    *   The backend runs YOLO and MiDaS, returning bounding boxes, depth estimations, and spatial positions, which are rendered live on the canvas.
    *   Audio alerts (TTS) will guide the user based on obstacle priority.
